## ✨ What is ExtAI Leo Happy?

**ExtAI Leo Happy** transforms your Chrome browser into a fast, streaming **Multi-Model AI Workspace** without bloated subscription lock-in:

- ⚡ **Instant Side Panel (`Ctrl+Q`) & Floating Quick Menu**: Highlight text on any webpage to translate, summarize, rewrite, explain, or quote directly into follow-up chat (**Continue Chat**).
- 🌐 **Real-Time Live Web Search**: Fact-check and synthesize real-time web results with cited source links directly from selected text.
- 📄 **PDF / Word (DOCX) & Multi-Image Vision**: Drop full documents or up to **6 images simultaneously** for OCR, charts, UI debugging, and Q&A.
- 🔐 **Dual Mode — Built-in Cloud AI or Local BYOK**: Start immediately on the Free Cloud tier or Pro Cloud Multi-AI, OR connect your own **OpenAI, Google Gemini, Anthropic Claude, xAI Grok, OpenRouter, or DeepSeek** API keys stored strictly in local browser storage.
- 🌍 **Multi-Language UI**: Full English, Vietnamese, and Chinese interface support.
